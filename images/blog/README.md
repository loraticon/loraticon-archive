# 블로그 목록 썸네일

이 폴더에 네이버 블로그 글 번호와 같은 이름의 WebP 이미지를 넣습니다.

- 권장 크기: 기존 네이버 썸네일과 같은 773 × 773px
- 화면 비율: 1:1 정사각형
- 권장 형식: WebP
- 파일명 예시: `224036403226.webp`
- 간단한 파일명 목록은 `thumbnail-files.txt`에서 확인할 수 있습니다.
- 글 제목, 카테고리, 소개 페이지까지 포함한 전체 대응표는 `thumbnail-map.csv`에서 확인할 수 있습니다.

이미지가 없어도 목록에는 로라티콘 기본 배경이 표시됩니다.
